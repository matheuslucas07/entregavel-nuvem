# Entregável - Computação em Nuvem

Projeto acadêmico de Computação em Nuvem com uma aplicação Web desenvolvida em HTML, CSS e JavaScript.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Node.js
- Servor
- Git e GitHub

## Estrutura

```text
entregavel-nuvem/
├── index.html
├── page2.html
├── script.js
├── styles.css
├── package.json
├── package-lock.json
├── .gitignore
└── README.md
```

## Como executar

Com o Node.js instalado:

```bash
npm install
npm start
```

O comando `npm start` inicia o servidor local usando o Servor.

Também é possível abrir `index.html` diretamente no navegador.

## Contexto acadêmico
